# FLOWER LIGHT — الموقع المؤسسي الجديد المستقل

**نسخة تطوير محلية مستقلة v0.3 (React + TypeScript + Vite).** أُنشئت منفصلة عن مستودع موقع Flower Light القديم؛ لا ترتبط بقاعدة Supabase القديمة ولا تعدّلها، ولا تحتوي أسرارًا.

## ما تحتويه هذه الحزمة

- صفحة رئيسية عربية واتجاه RTL بتصميم متجاوب للحاسوب والجوال.
- كتالوج منتجات ببحث بالاسم والكود وفلاتر مترابطة بحسب الأقسام ودرجة اللون والتركيب والتوفر.
- قائمة طلب عرض سعر تدعم إضافة المنتجات وتعديل الكمية بالكتابة (1–9999)، وتصدير الطلب كملف Excel أصلي (`.xlsx`) وإرساله اختياريًا عبر واتساب.
- تصدير الكتالوج إلى Excel **حقيقي** بدون مكتبات إضافية: صف العناوين ثابت، فلاتر، أحجام أعمدة، واتجاه RTL.
- معاينة داتا شيت عربي/إنجليزي مع زر **طباعة / حفظ PDF من نافذة الطباعة** (يستخدم محرك المتصفح للحفاظ على الخطوط العربية).
- محرر محلي للمنتجات وبيانات المنشأة في صفحة `?admin=preview`؛ ينبه صراحةً أنه **ليس إدارة مؤمنة** وأن الحفظ في `localStorage` فقط.
- صور إنارة توضيحية وتجريبية، و4 منتجات غير حقيقية. يجب استبدالها بالمنتجات والمواصفات المعتمدة قبل الاستخدام العام.

## التشغيل على Windows

1. فك ضغط ZIP في مجلد جديد بالكامل؛ **لا** تضعه داخل مشروع Flower Light القديم.
2. ثبّت Node.js 22 أو أحدث، ثم افتح PowerShell في المجلد الجديد.
3. نفّذ `npm install` (يتطلب اتصالًا بالإنترنت عند أول تشغيل).
4. نفّذ `npm run dev` ثم افتح الرابط الذي يظهر، غالبًا `http://127.0.0.1:5173`.
5. لفتح واجهة الإدارة المحلية أضف `?admin=preview` إلى رابط الصفحة.
6. للتأكد من كود المشروع: `npm run typecheck` ثم `npm run build`، وللاختبارات الأساسية `npm run test:core`.

## استخدام PDF

افتح بطاقة منتج ثم اضغط **الداتا شيت**. تظهر نافذة الطباعة؛ اختر **Save as PDF / حفظ كملف PDF** وحدد المقاس A4. لا يوجد حاليًا توليد PDF مباشر بضغطة واحدة؛ هذه طريقة طباعة المتصفح المتوافقة مع العربية.

## استخدام Excel

- أسفل الكتالوج: **تصدير قائمة المنتجات Excel**.
- من قائمة الطلب: **تصدير الطلب Excel**.
- ملفات `.xlsx` فعلية وليست ملفات CSV متنكرة. لا تُصدَّر بيانات الزوار ولا أسرار Supabase.

## تحسينات v0.3

- يمكن الآن كتابة كمية جديدة في القائمة بالكامل، بما فيها الأرقام العربية، دون أن يُحذف المنتج عند مسح الرقم مؤقتًا. تُطبّق الكمية عند الخروج من الحقل أو ضغط Enter؛ Escape يعيد الرقم السابق. الحذف يتم بزر «حذف» أو بتخفيض الكمية 1 عبر زر الناقص.
- عند بلوغ 30 صنفًا لا يُسقط الموقع صنفًا قديمًا بصمت؛ تظهر رسالة بدلًا من الإضافة.
- معاينة مرئية لورقة البيانات الفنية قبل الطباعة، مع زر حفظ PDF عن طريق طباعة المتصفح.
- محرر المعاينة المحلي يتيح تنزيل ملف JSON يحتوي المنتجات والإعدادات، واستيراده بعد تحقق وتأكيد. **الاستيراد يستبدل بيانات الجهاز ويفرغ قائمة الطلب**. لا يستورد ملف Excel مباشرةً.

## الفصل عن النظام القديم

- لا تستخدم `config.js` الخاص بموقع Flower Light القديم.
- لا توجد مفاتيح Supabase في هذا المشروع.
- لا يتطلب المشروع SQL، ولا يشغّل أي إجراء على قاعدة بيانات خارجية.
- لا تقم برفعه أو نشره قبل تنفيذ المصادقة الآمنة وRLS، ومراجعة البيانات الحقيقية، واختبارات Playwright الكاملة.

## ملاحظات التحقق

- اختبارات الوحدات ومولّد `.xlsx` تعمل دون تثبيت React، باستخدام TypeScript المتاح على الجهاز.
- اختبارات التشغيل الكاملة بـ Vite/React تعتمد على تنزيل حزم npm؛ في بيئة إعداد هذه النسخة لم يكن `registry.npmjs.org` متاحًا، لذا لا يُدّعى نجاح بناء Vite أو تشغيل Playwright أو حفظ البيانات في Supabase.
- `?admin=preview` للتجربة فقط، ولا يجوز اعتباره صلاحيات فعلية. التحويل لمدير آمن هو خطوة لاحقة مع Supabase مستقل.
