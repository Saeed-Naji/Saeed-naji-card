Flower Light — STAGE84 STABILITY

هذه نسخة تثبيت واختبار مبنية على النسخة السابقة بدون تغيير التصميم.

ما تم:
1) توسيع اختبار المتصفح ليضغط فعليًا على منتجاتنا، فتح/إغلاق الكتالوج، تحميل المنتج، تحميل القسم، تكبير الصور، السابق/التالي، واتساب، الكتالوج PDF، ونموذج بيانات العميل عند التفعيل والتعطيل.
2) تثبيت صلاحيات Admin 2 نهائيًا في الواجهة وEdge Function وSQL: المسموح فقط الإحصائيات، البيانات الشخصية، وسائل التواصل، جهات اتصال العملاء، وصمّم داتا شيت. الأقسام والمنتجات للمدير الأساسي فقط.
3) إزالة أي صلاحيات تاريخية غير مسموحة من حساب Admin 2 عند تشغيل SQL.
4) تنظيف أصل مشاركة الموقع: تم توحيد اسم أصل مشاركة الموقع إلى share-image.jpg مع الإبقاء على نفس الصورة.
5) إضافة اختبارات تمنع رجوع ملفات مراحل قديمة أو صلاحيات غير مرغوبة مستقبلًا.

الترقية من النسخة السابقة:
- ارفع كل ملفات STAGE84 مع الاستبدال.
- شغّل FINAL_SQL_STAGE84.sql مرة واحدة داخل Supabase > SQL Editor لأن هذه النسخة تشدد صلاحيات Admin 2 وتزيل أي صلاحيات قديمة مخزنة.
- لا يتغير التصميم ولا بيانات المنتجات.

مهم:
- Admin 2 لا يملك الأقسام أو المنتجات.
- المدير الأساسي وحده يدير الأقسام والمنتجات وإعداد طلب بيانات العميل.
- اختبارات GitHub الجديدة تعمل محليًا على نسخة المستودع قبل النشر، بينما live-site-check يفحص النسخة المنشورة.
