# تحويل تصميم Saeed إلى النمط المؤسسي المرجعي — v0.14

## المصدر
الملف المرفق من المستخدم: `Kimi_Agent_المرفقات المشتركة(1).zip` ويحتوي على تصميم React متعدد الصفحات بمظهر B2B صناعي/تجاري.
نفّذنا أسلوبه المرئي وتوزيع أقسامه في **مشروع Saeed المستقل**، ولم ننقل نظام قاعدة البيانات tRPC/Drizzle المرجعي، ولا بياناته أو علامته التجارية.

## التغييرات

- ألوان **أبيض، عاجي فاتح، برتقالي** بالاعتماد على `#ea580c`، خط عربي واضح، بطاقات وحدود خفيفة.
- رأس صفحة أبيض ثابت وتباعد مريح وروابط رئيسية، مع قائمة هاتف قابلة للفتح والإغلاق.
- Hero مصوّر كامل العرض، عنوان بارز وCTA برتقالي، متناسق مع سطح المكتب والجوال.
- ترتيب الأقسام كما في المرفق: **من نحن → القطاعات → فئات المنتجات → منتجات مميزة → الكتالوج كاملًا → الخدمات → أسباب الاختيار → مجالات المشاريع → طلب عرض سعر → التواصل → تذييل متعدد الأعمدة**.
- الفئات والمنتجات تأتي من **كتالوج Supabase الحالي نفسه**؛ لا تُنشأ منتجات جديدة وهمية في قاعدة البيانات ولا نتظاهر بوجود مشاريع منفذة.
- تغيير عرض بطاقات المنتجات والفلاتر وتناسقها مع الهوية الجديدة، والاحتفاظ بمعرض الصور ومواصفاتها والداتا شيت وقائمة الكميات.
- إعادة تنسيق صفحات `about.html` و`services.html` و`projects.html` و`contact.html` بنفس الألوان والخطوط، وإصلاح روابط الكتالوج الخاطئة.
- الحفاظ على لوحة مدير `?admin=1` وطلبات الأسعار وCloudflare Turnstile وبيان الخصوصية `?privacy=1` وسياسات RLS وقواعد البيانات دون أي تعديل.
- خلفية Hero الحالية من أصول موقع Saeed نفسه؛ لم نرفع مواد الشركة المرجعية أو ننسب مشاريعها إلى Saeed. استخدام صور وأمثلة في صفحة مجالات المشاريع **توضيحي فقط**.

## تشغيل واختبار

- افتح الموقع: https://saeed-naji.github.io/Saeed-naji-card/
- اختبر قائمة الهاتف، التنقل للأقسام، فئات المنتجات (اضغط فئة للتصفية)، الكتالوج، إضافة المنتج، الكميات، معرض الصور، الداتا شيت، وقائمة عرض السعر.
- اختبر جميع الصفحات المنفصلة، ثم اختبر لوحة المدير مع حساب المالك دون تغيير بيانات الإنتاج.
- يجب نجاح `npm run typecheck`, `npm run test:core`, بناء Vite، واختبارات الاتصال بـSupabase عبر GitHub Actions.
- فحص البناء لا يغني عن اختبار بصري حقيقي على 360px و390px و768px و1280px بعد النشر.
- **اسم الشركة ومحتوى المشاريع والخدمات والمنتجات ما يزال تجريبيًا حيث لم يُعتمد بعد**؛ التصميم لا يغيّر صحة البيانات.

## الحدود
- لا يوجد ربط بقاعدة البيانات الموجودة في الملف المرجعي؛ مشروع Saeed يستمر على Supabase `afrvoshsiqartsketiuv` فقط.
- لا يزيل هذا الإصدار الجداول القديمة الخمسة عشر في مشروع Saeed ولا يغيّر بيانات العملاء.
- لا يغيّر شيئًا في المستودع القديم `Basair-Alkhalij/Flower-light` أو قاعدة Supabase الخاصة به.
