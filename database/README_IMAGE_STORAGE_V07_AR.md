# رفع صور المنتجات — الموقع المؤسسي الجديد v0.7

هذه الميزة تخص **مشروع Saeed Naji فقط**: `afrvoshsiqartsketiuv`. لا تتصل بمساحة الصور القديمة `product-images`.

## ما تم تنفيذه

- أُنشئت مساحة تخزين **جديدة ومستقلة** باسم `corp-product-images`، مع `public=true` لأن الصور المعتمدة لكتالوج عام.
- قيود الملف على الخادم: **3 ميغابايت كحد أقصى**، والصيغ `image/jpeg` و`image/png` و`image/webp` فقط.
- سياسة `corp_images_admin_insert` تسمح برفع صور داخل المجلد `catalog/` لأعضاء جدول `corp_admin_members` المعتمدين فقط.
- سياسة `corp_images_admin_list` تسمح بعرض قائمة ملفات مساحة الشركة للمدير المعتمد فقط.
- لا توجد سياسات تحديث/حذف للصور الجديدة من متصفح الموقع؛ كل صورة تُرفع باسم UUID فريد (دون `upsert`).
- لا تتغير سياسات أو ملفات مساحات التخزين القديمة.
- فحص الواجهة يتحقق من نوع MIME وحجم الملف وتوقيع JPG/PNG/WebP الأساسي قبل الرفع.
- بعد الرفع يظهر رابط الصورة داخل نموذج المنتج مع معاينة. لا يُربط الرابط بمنتج حتى الضغط على **حفظ المنتج في Supabase**.
- بيانات جداول المنتجات تبقى محمية بسياسات RLS الموجودة.

## تجربة الاستخدام

1. افتح [لوحة الإدارة](https://saeed-naji.github.io/Saeed-naji-card/?admin=1).
2. سجّل دخولك بحساب `owner` المعتمد في **Supabase Saeed**.
3. اختر **إدارة المنتجات → إضافة منتج** أو تعديل منتج.
4. اختر الصورة من الكمبيوتر، JPG أو PNG أو WebP، أقل من 3 ميغابايت.
5. تحقق من ظهور معاينة الصورة ورسالة نجاح الرفع.
6. أكمل البيانات الفنية، ثم اضغط **حفظ المنتج في Supabase**.
7. افتح الموقع في نافذة خاصة وتحقق من ظهور الصورة عند نشر المنتج.

## حدود حالية

- **هذه الميزة تنشر صورًا عامة**: لا ترفع صورًا خاصة أو صور عملاء، لأن رابط الملف يستطيع أي شخص فتحه.
- الصور الحالية أحادية لكل منتج؛ دعم معرض متعدد الصور ومقاسات صور محسّنة سيأتي في تحديث منفصل.
- لا تتوفر إزالة الصور المرفوعة أو تنظيف الملفات غير المرتبطة بمنتجات بعد؛ إغلاق النموذج قبل حفظ المنتج قد يترك ملفًا غير مستخدم. لا تحذف صفوف `storage.objects` من SQL.
- نجاح اختبارات بناء GitHub ووجود سياسات RLS لا يثبت نجاح رفع فعلي بمستخدم؛ يلزم تجربة في المتصفح بحساب `owner`.
- احتفظ بمساحات النظام القديم كما هي حتى تأخذ نسخة احتياطية وتوافق على تنظيفه.
