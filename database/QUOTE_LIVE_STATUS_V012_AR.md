# حالة استقبال طلبات الأسعار في Saeed — 2 نوفمبر 2026

**المشروع:** Supabase Saeed Naji `afrvoshsiqartsketiuv` والموقع `https://saeed-naji.github.io/Saeed-naji-card/` فقط.
**ليس** مشروع Flower Light القديم في Basair-Alkhalij.

## تحققنا من الآتي

1. نجح نشر موقع React بواسطة GitHub Actions (تشغيل `41475922909`).
2. سجّلت اختبارات GitHub رسالة `Saeed quote configuration present: true`؛ هذا **لا يثبت صلاحية المفاتيح وحده**، لكنه يؤكد وجود إعدادات خادم Turnstile المطلوبة.
3. في قاعدة Saeed توجد **عملية تسجيل طلب واحدة** داخل `corp_quote_requests`، وحالتها `responded` (تم الرد). يوجد كذلك سجل واحد داخل `corp_quote_intake_log`. هذا دليل عملي على استعمال مسار الطلبات وحفظ الحالة، دون كشف اسم العميل أو وسائل الاتصال.
4. كود Edge Function v3 المنشور يطابق كود `supabase/functions/corp-submit-quote/index.ts` في GitHub.
5. اختبار صلاحيات SQL أكد أن `anon` لا يملك `SELECT` أو `INSERT` على الطلبات ولا `EXECUTE` على RPC، وأن المستخدم المسجل العادي لا يملك `INSERT` مباشر.
6. مهمة حذف بيانات منع التكرار الأقدم من 48 ساعة `saeed-corp-quote-rate-log-48h` مسجلة ونشطة. **هذه المهمة لا تحذف طلبات العملاء.**

## إضافة الإصدار v0.12

- تُظهر لوحة المدير عدد الطلبات بحالة «جديد» وآخر وقت تحديث لقائمة الطلبات.
- تُحدَّث قائمة آخر 100 طلب تلقائيًا كل دقيقة **عندما تكون لوحة المدير مفتوحة وظاهرة فقط**، بشرط مصادقة المالك.
- زر تحديث الطلبات يحدّث الطلبات وحدها، فلا يُعيد تحميل أو يستبدل المسودات غير المحفوظة من إعدادات الشركة والمنتجات.
- التحديث لا يرسل تنبيهات هاتف أو بريد، ولا يقوم بمراقبة خلفية خارج جلسة المتصفح المفتوحة.
- لا تُرسل معلومات العملاء إلى أي طرف ثالث عبر هذه الميزة؛ تُجلب من Supabase وفق RLS الموجود.

## ما يحتاج قرارًا وتحققًا إضافيين

- **سياسة خصوصية معتمدة** تحدد غرض جمع المعلومات، وسيلة التواصل، الجهة المتحكمة، ومدة احتفاظ طلبات العملاء. لا ننشر سياسة قانونية من عندنا دون تأكيد بيانات الشركة.
- **نسخة احتياطية مستقلة قابلة للاستعادة** قبل حذف 15 جدولًا قديمًا من مشروع Saeed وأصول Storage القديمة؛ لم تُحذف.
- اختبارات تسجيل الدخول الحقيقية والصور على المتصفح والجوال لا تزال خطوات تشغيلية مستقلة. لم يُعد المساعد تنفيذها بإرسال بيانات دخول المالك.
