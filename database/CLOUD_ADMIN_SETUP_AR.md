# إعداد لوحة المدير المستقلة — إصدار 0.4

**الحالة: الكود مجهز ولم يتم توصيل قاعدة بيانات بعد.** مشروع Supabase الوحيد المتاح أثناء التطوير يتبع Flower Light القديم، وقد تُرك دون أي تغيير.

## الخطوات الآمنة بالتسلسل

1. أنشئ مشروع Supabase **جديدًا ومستقلًا** بعد تحديد المؤسسة المالكة والمنطقة والتكلفة. لا تستخدم قاعدة Flower Light القديمة.
2. راجع ملف `SCHEMA_PROPOSAL_NOT_APPLIED.sql` ثم حوّله إلى Migration رسمي بمساعدة Supabase CLI، وطبقه فقط في المشروع الجديد.
3. عطّل التسجيل العام غير المطلوب في Auth. أنشئ مستخدم المدير يدويًا، مع بريد متحقق وكلمة مرور قوية وتحقق متعدد العوامل متى تيسر.
4. من SQL Editor الموثوق في **المشروع الجديد فقط** وبعد التأكد من UUID، سجّل المدير:
   `insert into public.corp_admin_members(user_id) values ('UUID-OF-NEW-ADMIN');`
   لا تمنح صلاحية كتابة `corp_admin_members` للمستخدمين.
5. نفّذ اختبارات RLS للزائر، والمستخدم المسجل غير المدير، والمدير. راجع Security Advisors.
6. في مستودع **Saeed-Naji/Saeed-naji-card** افتح Settings → Secrets and variables → Actions → **Variables** وأنشئ المتغيرين `CORP_SUPABASE_URL` و`CORP_SUPABASE_PUBLISHABLE_KEY` (العمومي فقط). لا تضف service_role.
7. بعد اكتمال نشر Pages افتح `https://saeed-naji.github.io/Saeed-naji-card/?admin=1`. يتطلب الوصول تسجيل الدخول ثم وجود عضوية في `corp_admin_members` ويتحقق RLS من كل طلب.
8. ابدأ بمنتج تجريبي `visible=false`، ثم اختبر ظهوره بعد نشره. اضبط `is_published` لبيانات المنشأة بعد الاعتماد.
9. لا تقبل طلبات زوار في `corp_quote_requests` حتى تكون هناك Edge Function للتحقق وTurnstile وحدود الاستخدام وسياسة خصوصية.

## ضوابط التنفيذ

- عند غياب متغيرات البيئة، يبقى الموقع في **وضع المعاينة** ولا تظهر لوحة المدير السحابية.
- عند تفعيل الربط، لا يعرض الزائر بيانات المتصفح المحلية إذا فشل الاتصال.
- **لا يوجد تسجيل مستخدم جديد** من شاشة المدير؛ الدخول للحسابات المعتمدة فقط.
- صفحة الإدارة وحدها ليست الحماية؛ RLS في قاعدة البيانات هو مصدر صلاحية الوصول.
- صور المنتجات في الإصدار الحالي روابط URL فقط؛ الرفع إلى Storage يحتاج سياسة مستقلة وتدقيقًا لاحقًا.
- استخدامه على المشروع القديم غير مسموح. لا تنشر بيانات الشركة الرسمية دون مراجعة.
